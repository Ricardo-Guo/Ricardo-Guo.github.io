Under the hood

Implementation details for readers who want to trace the full system from model output to evaluated robot behavior.

Temporal VLAFeature queue / Cross-frame decoding / Action chunks

A single-frame vision-language backbone emits learnable features. A FIFO history feeds a cross-frame diffusion decoder that predicts multi-step actions without re-encoding earlier frames.

Robot controlWidowX / 7D actions / Differential IK

The client maps position, axis-angle rotation, and gripper output into workspace-clipped absolute targets, then tracks them with Isaac Lab differential inverse kinematics.

Simulation stackIsaac Lab / Task runtimes / Camera separation

Four task-specific runtimes share robot, camera, action, artifact, and success-evaluation infrastructure. The policy camera is separate from the third-person presentation camera.

Robustness systemSimX-OR operators / 52 cells / Resumable orchestration

Seeded perturbations enter only the policy RGB stream. Isolated rollout sessions write videos, actions, metrics, and resumable matrix summaries with no missing cells or execution errors.
