项目案例

基于 OpenVINS 的无人机集群协同自定位系统

面向无 GPS 环境的无人机集群视觉惯性协同定位系统。

Source code
ROS2OpenVINS无人机C++SLAM

项目概览

这个项目围绕无人机集群在无 GPS 环境下的定位漂移问题展开，使用 OpenVINS、ROS2 通信架构和协同定位思路，构建一套视觉惯性里程计系统。

项目重点包括多机位姿估计、跨设备通信、仿真环境验证和后续硬件部署。当前页面先保留核心说明，后续可以继续补充真实实验视频、误差曲线和代码片段。

技术栈

模块工具 / 方法
中间件ROS2
视觉惯性估计OpenVINS, OpenCV, Eigen
仿真Gazebo, PX4 SITL
飞控PX4 Autopilot, MAVROS
优化Ceres Solver, g2o

关键挑战

  • 多机通信中的时延会影响位姿融合，需要对消息频率和 QoS 策略进行优化。
  • IMU 在振动环境下容易产生噪声尖峰，需要结合机械减振和软件异常值剔除。
  • 嵌入式平台算力有限，需要优化特征跟踪和滤波更新流程。

项目结果

该系统的目标是在室内、仓库等无 GPS 场景中实现稳定定位，并为后续的无人机集群探索、协同建图和任务分配打基础。
